# Mouse Hub

A small tray app for the HATOR Quasar 3 Ultra 8K Wireless mouse: DPI stages, polling rate, lighting,
buttons and profiles that switch by themselves when a game starts.

**Download:** the newest `MouseHub-<version>.exe` on the [Releases](../../releases/latest) page. It is one
file and needs nothing else installed (Windows 10 or 11, x64). Run it once: it puts itself in
`%LOCALAPPDATA%\Programs\Mouse Hub` and starts with Windows. It tells you when a newer version is out and
updates itself in one click.

Each release lists the SHA-256 of its file.

This repository only holds the releases.
